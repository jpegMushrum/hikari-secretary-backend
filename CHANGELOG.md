# История изменений

Все значимые изменения фиксируются в этом файле.

## [0.2.0-dev] — 2026-10-28

### Добавлено

- Проверка подписи и срока действия `Telegram.WebApp.initData` по официальному
  алгоритму Telegram.
- Начальная роль администратора: список разрешённых Telegram ID задаётся через
  `ADMIN_TELEGRAM_IDS`.
- Закрытый диагностический endpoint `GET /api/v1/admin/me` для проверки
  интеграции Mini App. Он возвращает данные только подписанному администратору.

### Безопасность

- API отклоняет отсутствующие, изменённые и устаревшие Telegram credentials с
  `401`, а подписанных пользователей вне списка администраторов — с `403`.
- PostgreSQL и API по-прежнему привязаны только к loopback-интерфейсу хоста.

## [0.1.0-dev] — 2026-10-27

### Добавлено

- Каркас Go backend с HTTP health endpoints.
- Docker Compose с PostgreSQL, мигратором и API.
- Версионируемые SQL-миграции и начальный OpenAPI-контракт.
