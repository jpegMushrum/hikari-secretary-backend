# Hikari Secretary Backend

Будущий бэкенд платформы Hikari Secretary. Он станет единым владельцем
бизнес-данных и API для Telegram-бота и административного Telegram Mini App.

## Назначение

- Go API для администраторов и внутренних клиентов платформы;
- PostgreSQL и версионированные миграции схемы;
- авторизация Mini App по Telegram `initData`;
- бизнес-правила мероприятий, регистраций, отзывов, публикаций и статистики;
- outbox и фоновые задачи, надёжно доставляющие запланированные действия.

## Границы

Бэкенд не должен зависеть от Telegram UI и не должен дублировать обработчики
Python-бота. После миграции бот и Mini App обращаются к этому сервису через
контракт API; прямой доступ этих компонентов к PostgreSQL не допускается.

## Планируемая структура

```text
cmd/            # точки входа сервисов
internal/       # домены, use cases, хранилища и HTTP-адаптеры
migrations/     # миграции PostgreSQL
openapi/        # версионируемый контракт API
deploy/         # Dockerfile и конфигурация сервиса
```

Репозиторий пока содержит только стартовую документацию. Реализация начнётся
после фиксации API-контракта и плана миграции с SQLite.
